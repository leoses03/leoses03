### En qué trabajo

**Diseño de interfaz.** Dirección de arte y sistemas de diseño propios. Tipografía, grilla, color y movimiento como decisiones, no como ajustes por defecto.

**Frontend y movimiento.** HTML, CSS y JavaScript sin andamios innecesarios; React y Vue cuando el problema los pide. Animación ligada al scroll y WebGL con Three.js, con una regla fija: el movimiento nunca se paga con Core Web Vitals.

**WordPress y e-commerce.** WooCommerce a fondo: precios por rol, checkout a medida, multi sucursal, carritos de cotización. Temas y plugins propios.

**Backend e infraestructura.** Laravel y Livewire, APIs REST propias, MySQL, Redis. VPS, Docker y nginx, incluido el servidor donde vive mi portafolio.
